# Atajos de teclado

Los atajos también aparecen en los menús y en los tooltips de los botones.

## Requests

| Atajo | Acción |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | Enviar el request activo, desde cualquier parte del editor. |
| <kbd>Esc</kbd> | Cancelar el request en curso. |
| <kbd>Ctrl</kbd>+<kbd>L</kbd> | Ir a la URL y seleccionarla. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> | Formatear el body JSON o XML. |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Buscar dentro del body de la respuesta (con el foco en la respuesta). |

## Pestañas

| Atajo | Acción |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>T</kbd> | Nuevo request en una pestaña nueva. |
| <kbd>Ctrl</kbd>+<kbd>W</kbd> | Cerrar la pestaña activa. |
| <kbd>Ctrl</kbd>+<kbd>Tab</kbd> | Pestaña siguiente. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Tab</kbd> | Pestaña anterior. |
| <kbd>Ctrl</kbd>+<kbd>1</kbd> … <kbd>Ctrl</kbd>+<kbd>8</kbd> | Ir a la pestaña en esa posición. |
| <kbd>Ctrl</kbd>+<kbd>9</kbd> | Ir a la última pestaña. |
| Clic con la rueda | Cerrar esa pestaña. |

## Barra lateral

| Atajo | Acción |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Ir al buscador. |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> | Mostrar u ocultar la barra lateral. |
| <kbd>F2</kbd> | Renombrar la colección o el request seleccionado. |
| <kbd>Supr</kbd> | Eliminar la colección o el request seleccionado, con confirmación. |
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd> <kbd>Inicio</kbd> <kbd>Fin</kbd> <kbd>Enter</kbd> | Moverse por el árbol. Ver [Moverse con el teclado](./colecciones#moverse-con-el-teclado). |

<kbd>F2</kbd> y <kbd>Supr</kbd> no actúan sobre el árbol mientras escribes en un campo de texto.

## Perfil

| Atajo | Acción |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Guardar el perfil ahora. |
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | Archivo › Nuevo. |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Archivo › Abrir. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | Archivo › Reubicar. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | Archivo › Ir al archivo. |
| <kbd>Ctrl</kbd>+<kbd>Q</kbd> | Salir. |

## Apariencia y preferencias

| Atajo | Acción |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>=</kbd> o <kbd>Ctrl</kbd>+<kbd>+</kbd> | Ampliar el zoom. |
| <kbd>Ctrl</kbd>+<kbd>-</kbd> | Reducir el zoom. |
| <kbd>Ctrl</kbd>+<kbd>0</kbd> | Zoom al 100 %. |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | Abrir Preferencias. |

## Menús y diálogos

| Atajo | Acción |
|---|---|
| <kbd>Alt</kbd>+<kbd>A</kbd> | Abrir el menú Archivo. |
| <kbd>Alt</kbd>+<kbd>J</kbd> | Abrir el menú Ajustes. |
| <kbd>↑</kbd> <kbd>↓</kbd> | Moverse por las opciones de un menú. |
| <kbd>←</kbd> <kbd>→</kbd> | Pasar de un menú al otro. |
| <kbd>Enter</kbd> | Elegir la opción o confirmar el diálogo. |
| <kbd>Esc</kbd> | Cerrar el menú o cancelar el diálogo. |
| <kbd>Tab</kbd> | Siguiente celda en las tablas clave/valor. |
